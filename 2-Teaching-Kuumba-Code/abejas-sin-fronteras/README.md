# Abejas Sin Fronteras / Bees Tropical Flavor

Custom static site for **Abejas Sin Fronteras** — raw native-bee honey and agroecological spices produced by campesino families in Nicaragua.

## Brand

- **Spanish (primary):** Abejas Sin Fronteras
- **English:** Bees Tropical Flavor
- **Founders:** Yorlis & Nills McCune
- **Practice:** Meliponicultura (native stingless bee keeping) · Agroecological farming
- **Network:** Red Nicaragüense de Meliponicultura — Sureste

## Tech

Static HTML/CSS/JS, built on a customized [Beeberry HTML5 Template](https://themeforest.net/item/beeberry-beekeeping-and-honey-online-shop-html5-template/43618342). Local dev runs through [browser-sync](https://browsersync.io/).

## Local development

```bash
npm install
npm run dev
```

Opens [http://localhost:3000](http://localhost:3000) with live reload on file changes.
