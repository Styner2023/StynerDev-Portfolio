What Happens At The Party

They are not simply playing finished games.

Every game starts as a real, working project they can open up. A guide sits with them, shows them where the code lives, and helps them change it. The moment a child moves a block and watches the character on screen respond, the game stops being something made for them — it becomes something they are making.

  • Open working game projects
  • Explore how the code works
  • Customize characters and artwork
  • Change collectibles and enemies
  • Design backgrounds and game worlds
  • Change sounds
  • Experiment with scoring
  • Change lives and timers
  • Adjust movement and speed
  • Change difficulty
  • Modify game mechanics
  • Experiment with additional code
  • Test their changes
  • Create their own version of a game
  • Leave with something they made

Optional Add-On

🕹️ Take-Home Programmable Game Console

Select Birthday Game Lab experiences may include a compatible programmable handheld game console. A customized MakeCode Arcade game can be loaded onto the device, so the coding experience does not end when the party does.

Depending on the package selected, this can be for the birthday child alone, or for multiple participating children — each carrying home a game with their own changes baked into it.

Play it. Code it. Make it yours. Take it home.

The take-home console is an optional add-on and is not included in every experience. Availability, compatible device options, and package details are confirmed with you directly before anything is booked.
